# RESONANCE AI4D Lab: Homepage Prototype

An improved homepage prototype for the RESONANCE AI4D Lab at Addis Ababa University, built as a technical exercise.

> Work in progress. Full documentation (assessment, decisions, limitations, AI disclosure) will be added.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
